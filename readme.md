# Система учета и мониторинга движения финансов

Учебный проект по реализации объектной модели и прототипа пользовательского интерфейса (GUI) в рамках **Лабораторной работы № 2**.

## Описание проекта

Система предназначена для ведения личного или семейного бюджета, контроля денежных потоков, учета доходов и расходов, а также мониторинга лимитов по категориям трат.

Реализация выполнена строго на основе предоставленной спецификации (текстового описания, BPMN- и ER-диаграмм) без использования сторонних библиотек.

### Роли пользователей
* **Обычный пользователь (`user`)** — просмотр баланса счетов, регистрация финансовых операций (доходов и расходов), установка лимитов бюджета, формирование аналитических отчетов и получение уведомлений о превышении лимитов.
* **Администратор (`admin`)** — управление справочниками (создание счетов и категорий) и создание резервных копий базы данных.

## Архитектура и структура проекта

Проект разделен на три логических слоя: модели данных, сервисный слой и пользовательский интерфейс.

```text
finance_tracker/
├── main.py                      # Точка входа в приложение
├── models/                      # Слой данных (сущности из ER-диаграммы)
│   ├── __init__.py
│   ├── user.py                  # Класс User (Пользователь)
│   ├── finance.py               # Классы Account (Счет), Category (Категория), Transaction (Транзакция)
│   └── analytics.py             # Классы Budget (Бюджет), Report (Отчет), Notification (Уведомление)
├── services/                    # Слой логики и хранения данных
│   ├── __init__.py
│   └── finance_system.py        # Класс FinanceSystem (заглушка БД и подсистем)
└── ui/                          # Графический интерфейс (Tkinter)
    ├── __init__.py
    ├── app.py                   # Контроллер приложения и навигации между окнами
    └── frames/                  # Экраны (окна) приложения
        ├── __init__.py
        ├── login_frame.py       # Окно авторизации
        ├── dashboard_frame.py   # Главный экран (Дашборд)
        ├── transactions_frame.py# Окно регистрации операций
        ├── budget_frame.py      # Окно планировщика бюджета и лимитов
        ├── reports_frame.py     # Окно аналитики и отчетов
        └── admin_frame.py       # Панель администратора
```

## Объектная модель

В пакете `models` реализованы все сущности, описанные на ER-диаграмме:

| Класс | Описание | Основные атрибуты |
| :--- | :--- | :--- |
| `User` | Пользователь системы | `user_id`, `name`, `login`, `password`, `role` |
| `Account` | Финансовый счет (карта, наличные) | `account_id`, `name`, `account_type`, `balance`, `user_id` |
| `Category` | Статья доходов или расходов | `category_id`, `name`, `category_type`, `parent_category_id` |
| `Transaction` | Денежная операция | `transaction_id`, `date`, `amount`, `comment`, `account_id`, `category_id`, `user_id` |
| `Budget` | Лимит трат по категории за период | `budget_id`, `limit`, `period`, `spent`, `category_id`, `user_id` |
| `Report` | Аналитический отчет | `report_id`, `period`, `report_type`, `user_id` |
| `Notification` | Системное уведомление о лимитах | `notification_id`, `text`, `date`, `user_id`, `budget_id` |

## Требования и запуск

* **Язык:** Python 3.8+
* **Зависимости:** только стандартная библиотека Python (`tkinter`, `dataclasses`, `datetime`, `typing`). Установка дополнительных пакетов не требуется.

### Инструкция по запуску

1. Клонируйте репозиторий:
   ```bash
   git clone https://github.com/LLangreSS/omis2
   ```
2. Запустите приложение:
   ```bash
   python main.py
   ```

### Тестовые учетные записи
* **Обычный пользователь:** логин `user`, пароль `1234`
* **Администратор:** логин `admin`, пароль `admin`
